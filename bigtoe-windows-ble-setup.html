Windows BLE MIDI Setup

Windows has no native BLE MIDI support. Two small free utilities bridge the gap between BigToe and your DAW or amp sim.

Running BigToe on Windows

On Mac and iOS, Bluetooth MIDI is built into the operating system — devices like BigToe are recognized automatically and appear directly in any MIDI-capable app. Windows doesn't have native BLE MIDI support, so two small utility apps are needed to bridge the gap.

DEVICE BigToe
BLUETOOTH BRIDGE MIDIberry
VIRTUAL PORT loopMIDI
DESTINATION Your software

MIDIberry handles the Bluetooth connection. It sees BigToe as a BLE MIDI device and receives its MIDI messages — something Windows itself can't do without help.

loopMIDI creates a virtual MIDI port on your system. Since MIDIberry and your DAW or amp sim are two separate applications, they can't share a MIDI connection directly — loopMIDI creates a named virtual cable that MIDIberry sends into, and your MIDI software receives from.

Both utilities are free, lightweight, and run silently in the system tray once set up.

What you need

  • MIDIberryFree — Microsoft Store
  • loopMIDIFree — tobias-erichsen.de
  • Your MIDI softwareDAW, amp sim, etc.

First-time setup only

Pair BigToe in Windows Bluetooth. You only need to do this once — Windows remembers the pairing.

  1. Power on BigToe.
  2. Go to Start → Settings → Bluetooth & devices, and make sure Bluetooth is on.
  3. Click Add device → Bluetooth, wait for BigToe to appear, and click it to pair.

Every time you use BigToe

1

Start BigToe and open the configuration UI

  1. Power on BigToe and put it on your foot.
  2. Connect your Windows machine to the BigToe Wi-Fi access point.
  3. Open a browser and go to http://bigtoe.local
Important — make sure the address starts with http://, not https://. Some browsers redirect to https automatically — if the page doesn't load, check the address bar and correct it manually.
2

Open loopMIDI

The port only needs to be created once — it's remembered after that.

  1. Open loopMIDI.
  2. If you haven't created a port before, type a name (e.g. BigToe) in the text field at the bottom and click +.
  3. Confirm the BigToe port is listed.
3

Connect BigToe via MIDIberry

  1. Open MIDIberry — it will automatically connect to BigToe.
  2. Under Input, confirm your BigToe device is selected.
  3. Under Output, select the BigToe loopMIDI port.
4

Set up your MIDI software

  1. Open your DAW or amp sim.
  2. In its MIDI settings, set the MIDI input to the BigToe loopMIDI port.
  3. Use MIDI Learn or manual mapping to assign BigToe's switches to parameters.

Keeping it running

  • loopMIDI and MIDIberry must both stay open in the background — they minimize to the system tray.
  • Both can be configured to launch at startup so they're always ready.

Troubleshooting

loopMIDI port not visible in MIDIberry or your software

Press Win + R, type services.msc, hit Enter, find Windows MIDI Service, right-click it and select Restart. This is a known issue on Windows 11 25H2.

Display scaling note

If your plugin UI appears too large to fit on screen, go to Start → Settings → System → Display → Scale and reduce it to 100%.
